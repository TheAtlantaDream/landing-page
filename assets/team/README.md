# Team photos

The About us page shows one photo per person. Until a photo is added, its coloured square shows instead.

| File | Card on the page |
| --- | --- |
| `member-1.webp` | Coder template + Whisper |
| `member-2.webp` | Go bridge |
| `member-3.webp` | Agent runner |
| `sethpfp.webp` ✅ added | Seth Voisine, Front end |

- **Crop:** square, about **400 × 400** px. The page shows it at 140 × 140.
- **Format:** WebP or JPG, **under about 100 KB**. If you use JPG, change the `src` in `index.html` from `.webp` to `.jpg`.
- **Describe the photo:** in `index.html`, replace the `TODO(team)` text in that photo's `alt="…"` with a short description, e.g. `alt="Seth smiling in a grey hoodie"`.
- Also put your name in the card's `<h3>` and in `data-name="…"` on the `<img>`. Each card has a comment block in `index.html` explaining what to change.
