# Team photos

The About us page shows one photo per person. Until a photo is added, its coloured square shows instead.

| File | Card on the page |
| --- | --- |
| `stephen.webp` | Stephen Sulimani, Coder template + Parakeet |
| `carter.webp` | Carter Tierney, Go bridge |
| `uyiosa.webp` | Uyiosa Nehikhuere, Agent runner |
| `seth.webp` ✅ added | Seth Voisine, Front end + design |

- **Crop:** square, about **400 × 400** px. The page shows it at 140 × 140.
- **Format:** WebP or JPG, **under about 100 KB**. If you use JPG, change the `src` in `index.html` from `.webp` to `.jpg`.
- **Describe the photo:** in `index.html`, change that photo's `alt="Photo of …"` to a short description, e.g. `alt="Stephen Sulimani smiling in a grey hoodie"`.
- Each card has a comment block in `index.html` explaining what to change.
